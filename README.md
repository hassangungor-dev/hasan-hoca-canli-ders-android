# Hasan Hoca Canlı Ders – Android

Samsung tabletler, Android telefonlar ve öğrencilerin mobil cihazları için canlı ders uygulaması.

## Özellikler

- Ders koduyla aynı toplantıya katılma
- Öğretmen ve öğrenci girişleri
- Kamera ve mikrofon
- Android ekran paylaşımı
- Resim içinde resim desteği
- Açık renk, tablet uyumlu arayüz

## APK indirme

GitHub sayfasında **Eylemler (Actions)** sekmesine girin. En son başarılı çalışmayı açıp `Hasan-Hoca-Canli-Ders-APK` dosyasını indirin.

## Önemli not

Toplantı altyapısı Jitsi Meet kullanır. Ekran paylaşımı Android izin ekranından başlatılır. Bulut kaydı, kullanılan toplantı sunucusunun kayıt hizmetini desteklemesine bağlıdır. Kayıt öncesinde katılımcılara mutlaka bilgi verilmelidir.
